# FedMed Project Structure

## Project Overview

FedMed is a privacy-preserving Brain Tumor Segmentation system using Federated Learning.

The project is divided into independent modules so that every team member can work separately while allowing seamless integration.

# Module Responsibilities

## 1. Medical Model Module

**Owners**
- Mohit
- Shreya

**Folder**

```
model/
```

Purpose

- Brain MRI Segmentation
- BraTS Dataset Loading
- 3D U-Net Architecture
- Training
- Evaluation
- Inference

Structure

```
model/

├── dataset/
│   ├── dataset.py
│   ├── transforms.py
│   └── preprocessing.py
│
├── networks/
│   ├── unet3d.py
│   └── blocks.py
│
├── training/
│   ├── train.py
│   ├── losses.py
│   ├── optimizer.py
│   └── checkpoint.py
│
├── evaluation/
│   ├── metrics.py
│   └── validate.py
│
├── inference/
│   ├── predict.py
│   └── postprocess.py
│
├── utils/
│   ├── config.py
│   ├── logger.py
│   └── seed.py
│
└── tests/
```

Expected Input

- MRI Images
- Learning Rate
- Epochs
- Batch Size

Expected Output

- model.state_dict()
- Dice Score
- IoU Score
- Validation Loss

This module must NOT contain

- Flower
- Networking
- Encryption
- Dashboard code

---

## 2. Federated Learning Module

**Owner**

Federated Learning Team

Folder

```
federated_learning/
```

Purpose

- Flower Server
- Flower Client
- FedAvg
- Weight Aggregation
- Communication

Imports

```
from model.networks.unet3d import UNet3D
```

Receives

```
model.state_dict()
```

Returns

```
Updated Global Model
```

Must NOT modify Medical Model code.

---

## 3. Privacy Module

**Owner**

Privacy Team

Folder

```
privacy/
```

Purpose

- Homomorphic Encryption
- Secure Aggregation
- Differential Privacy

Receives

```
model.state_dict()
```

Returns

Encrypted Parameters

Must NOT edit model architecture.

---

## 4. Dashboard Module

**Owner**

Dashboard Team

Folder

```
dashboard/
```

Purpose

Display

- Dice Score
- IoU
- Loss
- Training Progress

Receives

Metrics generated by Medical Model and FL modules.

Must NOT perform model training.

---

## 5. Backend Module

**Owner**

Backend Team

Folder

```
backend/
```

Purpose

Acts as the central controller.

Responsibilities

- Call Medical Model functions
- Call Federated Learning functions
- Pass Hyperparameters
- Collect Metrics
- Send data to Dashboard

Backend should never modify model code.

# Coding Standards

- Python 3.11
- PEP8 formatting
- Type hints where possible
- Relative imports inside each module
- Absolute imports between modules

Example

```
from model.networks.unet3d import UNet3D
```

# Git Workflow

```
main

    │

development

    │

feature/medical-model

feature/federated-learning

feature/privacy

feature/dashboard
```

All feature branches must be merged into **development** first.

Only tested code should be merged into **main**.
