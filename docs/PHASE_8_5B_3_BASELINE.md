## 1. Baseline Architecture Inspection

1. **Flower Server Lifecycle (`server/flower_server.py`):**
   - Server initializes strategy via `StrategyRegistry.create("FedAvg")` and wraps with `FlowerStrategyAdapter`.
   - Binds to gRPC socket (e.g. `0.0.0.0:8080`) via `fl.server.start_server()`.
   - Orchestrates multi-round client parameter retrieval $\to$ sample-weighted `FedAvg` aggregation $\to$ global weight distribution.

2. **Client Lifecycle & Parameter Transport (`client/flower_client.py`):**
   - Implements `flwr.client.NumPyClient`.
   - `get_parameters()`: extracts PyTorch weights as list of NumPy arrays (`[val.cpu().numpy() for _, val in model.state_dict().items()]`).
   - `fit(parameters, config)`: loads global weights into local model, performs local training on assigned patient cohort, calculates gradient norm and parameter delta, and returns `(updated_parameters, num_examples, metrics)`.
   - `evaluate(parameters, config)`: evaluates local loss and Dice.

3. **Sample-Weighted FedAvg Aggregation (`server/strategies/fedavg.py`):**
   - Computes exact sample-weighted elementwise average:
     $$W_{\text{global}} = \sum_{k=1}^K \frac{n_k}{N_{\text{total}}} W_k$$
   - Where $n_k$ is the genuine sample count returned by client $k$, and $N_{\text{total}} = \sum n_k$.

4. **Global Validation Lifecycle:**
   - Evaluated after each round on the held-out `VALIDATION` subject (`BraTS2021_00002`) using independent `compute_dice()` and `compute_iou()` from `evaluation/metrics.py`.
   - `TEST` cohort (`BraTS2021_00001`) remains strictly firewalled and uninstantiated.
