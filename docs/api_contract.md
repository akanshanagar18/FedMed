## Purpose
Defines the REST and WebSocket contracts between the FastAPI backend, the React frontend, and the central Flower server telemetry streams.

## Endpoints (Draft)

### GET `/api/v1/health`
- **Purpose**: Health check for orchestration.
- **Response**: `{"status": "ok", "active_clients": int}`

### GET `/api/v1/metrics/rounds`
- **Purpose**: Fetch historical metrics for all completed rounds.
- **Response**: Array of round metric objects (Loss, Dice Score).

### WS `/ws/telemetry`
- **Purpose**: Stream live training updates to the React dashboard.
- **Payload**: `{"event": "round_start|round_end|client_update", "data": {...}}`

## Implementation Notes
- All endpoints must be validated using Pydantic schemas located in `common/schemas.py`.
- Strict OpenAPI specification will be auto-generated by FastAPI.
