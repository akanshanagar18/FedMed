# Contributing to FedMed

Thank you for your interest in contributing to FedMed!

## Guidelines for Pull Requests

1. **Fork and Branch:** Create a feature branch off `main` (e.g., `feature/your-feature-name`).
2. **Coding Standards:** Ensure Python code adheres to Black formatting and PEP 8 guidelines.
3. **Pydantic Schemas:** Place all shared network schemas in `common/schemas.py`.
4. **Automated Tests:** Add pytest unit or integration tests for new functionality under `tests/`.
5. **CI Verification:** Ensure all tests pass (`pytest`) before requesting code review.

## Reporting Issues

* Open a GitHub issue using the Bug Report or Feature Request template.
* Include full terminal output tracebacks when reporting bugs.
